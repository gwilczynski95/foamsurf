# Disentanglement Phase 1

Phase 1 is a 97-run, single-mechanism screening matrix. Every run starts from
the clean joint baseline, trains only on `lego_both`, uses seed 0 and the K=64
renderer, and keeps the qualified full-image L1+0.2 DSSIM objective. The
aligned `lego_lego` and `lego_clouds` images remain evaluation-only targets.

## Matrix

| Array indices | Count | Family |
|---:|---:|---|
| 0 | 1 | unchanged control |
| 1–40 | 40 | opacity binarization: 5 weights × 8 ramps |
| 41–72 | 32 | graph density TV: Huber weight/delta/schedule plus L1/L2 controls |
| 73–84 | 12 | adaptive density cap: rolling/EMA/warmup-freeze × quantile × multiplier |
| 85–88 | 4 | optical-thickness sparsity |
| 89–92 | 4 | opaque-if-used |
| 93–96 | 4 | opacity-pruning threshold |

The manifest is generated by
`training/disentanglement_sweeps.py`. Each entry has a unique label and an
explicit set of overrides. Tests verify that no undeclared scientific setting
changes relative to `configs/baseline_clean_joint.yaml`.

## Loss definitions

- Opacity binarization is the primitive mean of `alpha * (1 - alpha)`.
- Opaque-if-used is normalized by detached accumulated Gaussian contribution.
- Graph TV uses each undirected Delaunay edge exactly once with unit edge
  weight and mean reduction.
- Density cap excludes artificial guard sites and penalizes squared relative
  excess, `(density / cap - 1)^2`.
- Optical thickness is computed as `mean(-log(T_medium))` from an additional
  differentiable medium-only render, not from detached diagnostics.

All scheduled weights are zero before their start, increase with an exact
linear/cosine/quadratic ramp, and remain at the configured final value. Raw,
weighted and schedule values are logged separately.

The dynamic cap threshold is detached. `rolling` follows the current quantile,
`ema` smooths it, and `warmup_freeze` calibrates it through iteration 5000 and
then keeps it fixed. Cap state is included in checkpoints and restored on
resume.

## Submit

```bash
cd /shared/results/gmwilczn/foamsurf/foamsurf
sbatch scripts/sweep_disentanglement_phase1.sbatch
```

The array is limited to eight concurrent jobs. To launch only one family, use
an explicit range, for example:

```bash
sbatch --array=1-40%8 scripts/sweep_disentanglement_phase1.sbatch
```

Outputs are written under `outputs/disentanglement_phase1`. Each output keeps
only overwritten `best.pt` and `last.pt` checkpoints rather than one file per
checkpoint interval.

After the array finishes, aggregate the final metrics with:

```bash
python scripts/summarize_disentanglement_phase1.py
```

This writes `outputs/disentanglement_phase1/phase1_summary.csv`.

## Selection criteria

Do not rank runs solely by hybrid PSNR. At minimum compare hybrid and isolated
branch quality, Gaussian weight on cloud-only pixels, medium weight on
lego-only pixels, opacity polarization, density quantiles, graph TV, optical
thickness, point counts and stability of adaptation events.
